# 中国剪纸非遗数字文化可视化平台

## 项目介绍

基于 Vue3 + TypeScript + ECharts + SVG 开发的非遗文化数字可视化平台。

通过数据可视化、地域探索、传承分析以及参数化剪纸生成等方式，实现中国剪纸文化的数字化展示。

## 技术栈

- Vue3
- TypeScript
- Vite
- Vue Router
- ECharts
- SVG
- CSS3

## 功能模块

### 全国总览

- 中国地图可视化
- 剪纸项目地域分布
- 数据排行

### 地域探索

- 地域剪纸文化展示
- 风格分析
- 代表项目介绍

### 传承与流派

- 国家级代表性传承人展示
- 南北剪纸风格对比
- 流派关系分析

### 数字剪纸实验室

- 参数化剪纸生成
- 折数控制
- 纹样选择
- 风格选择
- SVG作品导出

## 运行

安装：

pnpm install

启动：

pnpm dev

打包：

pnpm build
